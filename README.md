## 1 - Simple_Reflex_Agent(简单反射代理):
**Task Environment Details:** 

- Performance Measure: Cleanliness (one point per clean square are each time step)
- Environment: World is divided into two squares A & B. 
- Sensors: The agent can assess if the squares are dirty or clean. 
- Actuators: The agent can clean the square or move onto the next square.

## 2 - Informed_Search_Algorithms(信息搜索算法)
**Informed Search Algorithms**

Implement the A* algorithm for the 3x3 sliding puzzle. As your program runs, it should output which node is being expanded during each iteration of the search & the **f(n)** value of that node. The program end when it either finds a possible solution (and output the solution sequence) or should tell the user if there is no solution.
